# csv-xml-analyzer

Консольное приложение для анализа справочников адресов в форматах CSV и XML (практическая работа № 3 по ООП).

По введённому пути к файлу приложение выводит:

1. дублирующиеся записи с количеством повторений;
2. количество 1, 2, 3, 4 и 5-этажных зданий в каждом городе;
3. время обработки файла.

После вывода статистики приложение снова ждёт путь к файлу. Ошибки (нет файла, неизвестный формат, битый XML, некорректные строки) выводятся сообщением и не завершают работу.

## Формат файлов

CSV — разделитель `;`, первая строка — заголовок, текстовые поля в кавычках:

```
"city";"street";"house";"floor"
"Барнаул";"Дальняя улица";56;2
```

XML — элементы `item` с атрибутами:

```xml
<root>
<item city="Барнаул" street="Дальняя улица" house="56" floor="2" />
</root>
```

Файлы читаются в кодировке UTF-8. Примеры лежат в папке [`samples`](samples).

## Структура

| Пакет | Назначение |
|-------|------------|
| `model` | `Address` — запись справочника |
| `parser` | общий контракт `AddressParser`, реализации `CsvAddressParser` и `XmlAddressParser`, выбор парсера по расширению в `ParserRegistry` |
| `statistics` | `StatisticsCollector` — подсчёт дубликатов и этажности |
| `service` | `AddressFileAnalyzer` — связывает парсер и статистику, замеряет время |
| `console` | `ConsoleApplication` — цикл ввода команд, `ReportPrinter` — вывод отчёта |

Чтобы добавить новый формат, достаточно реализовать `AddressParser` и зарегистрировать его в `Main`.

## Производительность

- Парсеры потоковые: CSV разбирается построчно собственным разборщиком, XML читается через StAX без построения дерева в памяти. Записи сразу передаются в сборщик статистики.
- Дубликаты считаются через `HashMap<Address, Integer>`, этажность — через `HashMap<String, int[]>`, всё за один проход по файлу.
- Этажность считается по уникальным зданиям: повторяющиеся записи не увеличивают счётчик.
